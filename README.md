
# Public API Gateway & Orderbook Stream Dashboard 🚀

Этот репозиторий представляет собой **публичный слой интеграции (Web API Gateway)** для моей распределенной платформы алгоритмической торговли криптовалютами.

Сервис предназначен для высокопроизводительного асинхронного чтения, валидации и визуализации потоковых данных стаканов (Orderbook), которые аккумулируются торговым ядром из 11 крипто-активов в режиме реального времени.

## 🧱 Архитектурная роль компонента

В общей экосистеме платформы данный шлюз решает ключевую задачу безопасности — **изоляцию торгового ядра от внешних клиентов**.
Вместо предоставления прямого доступа к внутренней инфраструктуре, внешние запросы (будь то работодатели, веб-интерфейсы или сторонние скрипты) общаются исключительно с этим изолированным асинхронным шлюзом на FastAPI.

Домашний Парсер ──(WS/REST)──> [ Локальный Redis Streams ]
│
(Асинхронное чтение)
▼
Пользователь ──(HTTPS)──> [ Cloudflare ] ──> [ FastAPI Сервер ] ──> [ HTML / REST JSON ]

## 🛠 Технологический стек шлюза

* **Framework:** FastAPI (Python 3.12+) — полностью асинхронная обработка входящих сессий.
* **In-Memory DB:** Redis Streams — извлечение последних обновлений стаканов на базе Low-Latency таймсерий.
* **Data Validation:** Pydantic v2 — строгая валидация типов данных и автоматическая генерация OpenAPI (Swagger) схем.
* **Frontend:** Чистый HTML5 + JavaScript (AJAX) — точечное обновление котировок без полной перезагрузки страниц.
* **Network & Security:** Cloudflare Tunnel — криптографический outbound-only туннель для защиты хоста от внешнего сканирования портов.

## ⚡️ Реализованные защитные механизмы

1. **Кастомный In-Memory Rate Limiter (Защита от DDoS):**
   Вместо использования тяжелых внешних библиотек, в код интеграционного шлюза встроен собственный легковесный Rate Limiter. Используя атомарные операции Redis `INCR` и `EXPIRE`, алгоритм ограничивает частоту вызовов с одного IP-адреса (**до 10 запросов за 10 секунд**). При превышении лимита Redis автоматически вешает TTL, а FastAPI мгновенно отсекает клиента с HTTP-статусом `429 Too Many Requests`, не нагружая процессор.
2. **Оптимизация рендеринга на фронтенде (AJAX):**
   Для минимизации задержек отображения высокочастотных данных стандартный механизм Server-Side Refresh был заменен на клиентский JavaScript-опрос через `fetch()`. Страница загружается один раз, а данные в DOM-дереве обновляются атомарно каждую секунду, исключая мерцание вкладки и лишний трафик.
3. **Валидация роутинга через литералы типов:**
   Использование конструкций `Literal` на уровне query-параметров FastAPI позволяет отсекать мусорные запросы к неподдерживаемым торговым парам на этапе валидации ASGI-интерфейса, предотвращая ложные обращения к Redis.

## 📈 Поддерживаемые активы

Система в реальном времени валидирует и обрабатывает стаканы для 11 ключевых пар:
`BTCUSDT`, `ETHUSDT`, `ETCUSDT`, `SOLUSDT`, `TRXUSDT`, `BNBUSDT`, `DOGEUSDT`, `ALEOUSDT`, `NEXAUSDT`, `XELUSDT`, `CETUSUSDT`.

## 🚀 Быстрый запуск локально

1. Установите зависимости проекта:

```bash
pip install fastapi "fastapi[standard]" redis pydantic
```

2. Запустите асинхронный сервер FastAPI:

```bash
fastapi dev Cripto_API.py
```

3. Для публикации шлюза в глобальный интернет без раскрытия локального IP запустите туннель Cloudflare:

```bash
cloudflared-windows-amd64.exe tunnel --url http://localhost:8000
```

Интерактивный пульт управления (Swagger UI) развернется по адресу `https://<your-subdomain>://`.
