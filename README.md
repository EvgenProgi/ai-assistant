# Local AI Voice Assistant (Vosk + Ollama/Mistral + VLC) 🎙️🤖

Автономный локальный голосовой ассистент («Умный экран») для управления медиа-инфраструктурой компьютера в реальном времени. Система работает полностью **offline**, не требует интернет-соединения, не отправляет данные на внешние сервера и использует синергию легковесных локальных нейросетей.

## 🚀 Ключевые особенности и архитектура

Проект построен на базе гибридной архитектуры (детерминированные правила + фолбек на LLM), что обеспечивает мгновенный отклик на базовые команды и гибкость ИИ при поиске контента:

1. **STT-слой (Speech-to-Text):** Потоковая обработка и распознавание аудио с микрофона в реальном времени через связку `PyAudio` и локальной модели `Vosk`.
2. **State Machine (Управление состоянием):** Конечный автомат, реализующий триггеры «сна» и «пробуждения» микрофона для предотвращения ложных срабатываний от фонового шума или колонок.
3. **NLP & Текстовая нормализация:** Собственные алгоритмы автоисправления поврежденного текста при ошибочной раскладке клавиатуры и кастомный парсер строковых числительных (например, «сорок две минуты» -> `2520` секунд).
4. **LLM Интеграция (Function Calling):** Использование локальной языковой модели `Ollama / Mistral`. Через системный промптинг модель обучена строгому извлечению интентов и возврату данных в формате структурированного `JSON` для последующего вызова Python-функций.
5. **Медиа-движок:** Прямое программное управление плеером через `VLC API` (фоновый прогрев сессий, точечное управление громкостью, полноэкранным режимом и тайм-кодами).

## 🛠️ Технический стек

* **Language:** Python 3.x
* **AI/ML:** Ollama (Mistral), Vosk Speech Recognition API
* **Audio & Video:** PyAudio, VLC API
* **Protocols & Formats:** JSON (Structured Output / Tool Calling)

## 📁 Структура логики (Цикл обработки)

[ Микрофон ] -> (PyAudio)
↓
[ Аудиопоток ] -> (Vosk STT)
↓
[ Сырой Текст ] -> (Фильтр раскладки & Триггеры сна микрофона)
↓
[ Валидный Текст ]
↓
├── (Детерминированные правила: Громкость/Перемотка/Пауза) -> Мгновенное исполнение в VLC
└── (Сложный поиск по названию) -> [ Ollama / Mistral ] -> [ JSON ] -> Исполнение в VLC

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com
cd YOUR_REPO_NAME
```

2. **Установите зависимости:**
   Убедитесь, что в системе установлен плеер VLC (архитектуры x64, совпадающей с вашей версией Python).

```bash
pip install pyaudio vosk python-vlc requests
```

3. **Скачайте модель распознавания речи:**

* Скачайте русскую модель Vosk (например, `vosk-model-small-ru-0.22` или полную версию).
* Распакуйте её в корень проекта в папку с именем `model`.

4. **Запустите Ollama:**
   Убедитесь, что у вас установлена и запущена утилита Ollama с загруженной моделью Mistral:

```bash
ollama run mistral
```

5. **Запуск ассистента:**

```bash
python assistant.py
```
